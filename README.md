Start with Cloudflare Workers and progress through hands-on labs covering KV, D1, R2, Workers AI, Vectorize, AI Gateway, Durable Objects, event-driven architecture, observability, and browser automation. Learn each service through real engineering scenarios, then integrate your skills in projects that build and operate APIs, data systems, RAG agents, and automation services. Along the way, develop practical abilities in development, deployment, testing, operations, and troubleshooting on Cloudflare.
