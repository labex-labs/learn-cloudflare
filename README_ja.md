Cloudflare Workers から始め、段階的な実習ラボを通じて KV、D1、R2、Workers AI、Vectorize、AI Gateway、Durable Objects などの主要サービスを習得し、さらにイベント駆動アーキテクチャ、可観測性、ブラウザ自動化へ進みます。各段階では実際のエンジニアリング場面を扱い、個々の機能を学んだ後、総合プロジェクトで API、データシステム、RAG エージェント、自動化サービスを構築・運用します。Cloudflare アプリケーションの開発、デプロイ、テスト、運用、トラブルシューティングを実践的に身につけられる学習パスです。
