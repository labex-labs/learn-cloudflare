<h1 align="center">Cloudflare 배우기</h1>

<p align="center"><strong>실제 실습을 중심으로 단계별로 배우는 무료 실전 학습 경로입니다.</strong></p>

**언어:** [English](README.md) · [简体中文](README_zh.md) · [日本語](README_ja.md) · [Español](README_es.md) · [Français](README_fr.md) · [Deutsch](README_de.md) · [Русский](README_ru.md) · [한국어](README_ko.md) · [Português](README_pt.md)

Cloudflare Workers에서 시작해 단계별 실습으로 KV, D1, R2, Workers AI, Vectorize, AI Gateway, Durable Objects 등의 핵심 서비스를 익히고, 이벤트 기반 아키텍처, 관측 가능성, 브라우저 자동화까지 확장합니다. 각 단계는 실제 엔지니어링 시나리오를 바탕으로 개별 기능을 먼저 학습한 뒤 API, 데이터 시스템, RAG 에이전트, 자동화 서비스를 구축하고 운영하는 종합 프로젝트로 연결됩니다. 이를 통해 Cloudflare 애플리케이션의 개발, 배포, 테스트, 운영, 문제 해결에 필요한 실무 역량을 체계적으로 갖출 수 있습니다.
