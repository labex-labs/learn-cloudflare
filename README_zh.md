<p align="center"><strong>一条免费、实用、循序渐进的学习路径，用真实动手练习掌握技能。</strong></p>

**支持语言:** [English](README.md) · [简体中文](README_zh.md) · [日本語](README_ja.md) · [Español](README_es.md) · [Français](README_fr.md) · [Deutsch](README_de.md) · [Русский](README_ru.md) · [한국어](README_ko.md) · [Português](README_pt.md)

本学习路径以 Cloudflare Workers 为起点，通过循序渐进的动手实验，带你掌握 KV、D1、R2、Workers AI、Vectorize、AI Gateway、Durable Objects 等核心服务，并进一步学习事件驱动架构、可观测性与浏览器自动化。每个阶段都以真实工程场景展开，先学习单项能力，再通过综合项目解决 API 交付、数据管理、RAG 智能体和自动化服务等实际问题，帮助你逐步建立开发、部署、测试、运维与故障排查 Cloudflare 应用的完整能力。
