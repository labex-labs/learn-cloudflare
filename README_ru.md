<h1 align="center">Изучайте Cloudflare</h1>

<p align="center"><strong>Бесплатный практический учебный маршрут с пошаговым освоением навыков.</strong></p>

**Языки:** [English](README.md) · [简体中文](README_zh.md) · [日本語](README_ja.md) · [Español](README_es.md) · [Français](README_fr.md) · [Deutsch](README_de.md) · [Русский](README_ru.md) · [한국어](README_ko.md) · [Português](README_pt.md)

Начните с Cloudflare Workers и последовательно осваивайте KV, D1, R2, Workers AI, Vectorize, AI Gateway, Durable Objects, событийную архитектуру, наблюдаемость и автоматизацию браузера в практических лабораторных работах. Каждый этап основан на реальных инженерных сценариях: сначала вы изучаете отдельные возможности, а затем объединяете их в проектах по созданию API, систем данных, RAG-агентов и сервисов автоматизации. Этот путь формирует практические навыки разработки, развёртывания, тестирования, эксплуатации и устранения неполадок в приложениях Cloudflare.
